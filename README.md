# 符文深渊 · RUNE ABYSS

一个**单 HTML 文件**、零依赖、零注释的传统 Roguelike。打开就能玩，程序生成、永久死亡、回合制、网格移动、物品鉴定、符文深渊第 15 层的暴君在等着你。

- **在线游玩**：`https://daoge96.github.io/rune-abyss/`（GitHub Pages）
- **本地游玩**：下载 `index.html`，双击用浏览器打开即可。没有构建、没有网络请求、没有第三方库。
- **指定种子**：`index.html?seed=123456&cls=mage` 用同一个种子开局，方便和朋友比深度。
- 文件内 **0 条注释**（无 `//`、无 `/* */`、无 `<!-- -->`），约 3500 行。

## 做了什么（系统清单）

- **程序生成**：BSP 房间+走廊、元胞自动机洞穴、编织迷宫、王座竞技场四种算法，按深度切换 6 套主题（苔石厅堂 / 低语岩洞 / 沉没墓窟 / 熔火矿坑 / 虚空回廊 / 深渊王座）；连通性用泛洪校验 + 保底挖通，另有密室（暗门后的宝库）与商店。
- **视野与记忆**：八分圆对称投影视野、明暗房、已探索地形记忆、洞察卷轴/药水与魔法地图。记住的怪物以暗影显示。
- **回合与速度**：能量制，速度参与结算（迅捷/迟缓/冰缓/加速），怪物按速度获得行动次数。
- **战斗**：d20 命中对抗、暴击、护甲减伤、六种元素与抗性、状态（中毒/灼烧/流血/冰缓/麻痹/僵化/沉睡/混乱/虚弱/疫病/诅咒/再生/隐身/护盾/漂浮/恐惧）、击退、劈砍、吸血、反击、处决、背刺。
- **26 种怪物**：各有独立 AI——成群、飘忽、远程放箭、治疗同伴、召唤亡灵、自爆（有引信预警）、偷东西后开溜、穿墙幽魂、被击中就分裂的镜影、再生巨魔、石化凝视、贴脸伏击的刺客，以及三阶段、会蓄力新星并召唤守卫的最终 Boss。
- **物品与鉴定**：60+ 种物品。药水/卷轴/法杖每局随机外观，未知时先鉴定；喝一口就认识，知识会跨局保留在浏览器里。诅咒装备卸不下来，要解咒卷轴。附魔、充能、投掷、法杖射线、火球、冰爆、变形、死亡射线。
- **资源与节奏**：饱食度时钟、干粮、Brogue 式「按深度补足」的保底生成（治疗药水 / 食物 / 附魔 / 鉴定卷轴不会断供）、每 150 回合游荡怪、脆皮前期与陡峭后期。
- **陷阱与环境**：8 种陷阱（含隐藏）、水、熔岩、碎石、冰面、祭坛、喷泉；门可以关门打狗，熔岩能烧死敌人。
- **成长**：20 项天赋随机三选一、等级成长、职业被动、4 个职业（战士/盗贼/法师/游侠）玩法差异极大。
- **永久死亡与元进度**：死亡结算（死因、深度、击杀、回合）、图鉴（已识别物品 + 已见怪物）、历史最好成绩、职业统计。
- **存档**：每层与每 25 回合自动存本地，关掉页面可以「继续上次的冒险」。
- **表现层**：纯 Canvas 绘制的 CRT 风界面、光照衰减、粒子、飘字、屏幕震动、命中停顿、程序化 WebAudio 音效与环境音、极简汉化 UI。

## 为什么这样设计（先查资料，再写代码）

动手前先查了「什么让 roguelike 出色」，结论直接写进了系统里：

1. **Berlin Interpretation 的高价值项**（程序生成、永久死亡、回合制、网格、非模态、复杂度、资源管理、探索与发现）全部实现，且都做成系统而非数值堆料。
2. **John Harris《Roguelike 设计的八条法则》**：
   - *No beheading*——不做「一击必死且无法反应」：Boss 新星、自爆虫都有 1 回合预警；石化、冰冻都是延迟生效。
   - *Play the player, not the character*——知识跨局保留（图鉴、物品外观），下一局你会更强，而不只是数字更大。
   - *Reasonable play 可行*——不在危险环境里乱喝未知药水是安全的，因为绝大多数时候你能退出战斗、休息、回到安全区再鉴定。
   - *Choices, not chores*——饥饿时钟宽松但真实；自动探索、休息、一键拾取把操作噪音压到最低。
3. **Brogue 的公平性思路**：关键资源「橡皮筋」生成（治疗/食物/附魔按深度保底补足），保证任何一局都不会因为没刷到治疗药水而崩盘；同时地形（门、走廊、水、熔岩、陷阱）是可用的战术资源。
4. **Agency 优先于随机**：随机只发生在「决定之前」（开局、掉落、地图），玩家总能通过撤退、关门、投掷、传送来回应；不会出现无解开局。
5. **死亡要有信息量**：死因、深度、击杀、回合、历史最佳全部结算，失败转化为下一局的知识。

## 验证方式（不是「看起来能跑」）

因为只有一次机会，写了三层自动化验证：

- `dev/harness.js`：把 `index.html` 里的脚本抽出来，在 Node `vm` 沙箱里用桩 Canvas / DOM / localStorage / WebAudio 跑真实游戏代码。
- `dev/tests.js`：**约 1.7 万条断言**。覆盖：15 层 × 12 种子生成的连通性与合法性、视野对称性、26 种怪物 AI 逐个对打、全部物品使用/装备/投掷/射线、全部陷阱与状态、存读档往返、随机按键猴子测试、11 种界面模式与 5 种窗口尺寸渲染（含 NaN 扫描）、死亡/复活/通关路径、BOSS 三档装备强度对局、以及一个自动玩家跑完整局。
- `dev/cdp.js`：用 Chrome DevTools Protocol 真机截图 25 张（标题、职业、游戏、背包、角色、帮助、地图、第 10 层、王座、死亡、升级、通关、图鉴、窄屏、手机竖屏），并收集浏览器控制台异常——最终 **0 异常**。

运行：

```bash
node dev/tests.js index.html
node dev/pro.js 20
node dev/boss.js
node dev/cdp.js
```

## 技术说明

- 单文件、无依赖、无注释、无外部资源；所有图形都是 Canvas 2D 图元与 Unicode 字形，所有声音都是 WebAudio 现场合成。
- 全程确定性随机（mulberry32 + 种子），同一个种子会生成完全相同的深渊。
- 存档用压缩打包（地形/记忆/光照按字符编码）写入 `localStorage`，不联网。
- 自适应布局：宽屏为右侧信息栏，窄屏为底部 HUD，触屏追加虚拟手柄。
